# TSDP2 · Entrega 1 · Tasca 2 — Investigació UX

## Comparativa de dues plataformes amb les heurístiques de Nielsen

**Projectes:** Rocanolich · Estètica i perruqueria · Graduació  
**Modalitat:** individual · **Lliurament:** dins del mateix dossier de Google Drive iniciat a la tasca 1 (no cal un document nou).  
**Data límit:** 30 d’octubre de 2026.

## 1. Objectiu

Investigar com resolen un problema semblant **dues plataformes reals**, detectar bones pràctiques i problemes d’usabilitat i transformar els resultats en decisions justificades per al propi projecte. Analitzar la **facilitat d’ús**, no només l’estètica.

## 2. Normes per seleccionar les plataformes

1. **Cada alumne escull dues plataformes diferents** relacionades amb el seu projecte. Poden ser webs o aplicacions.
2. **Dins del mateix grup de projecte, no es pot repetir cap plataforma entre alumnes.** Cal acordar i registrar prèviament la selecció entre tots els integrants. Si una plataforma ja ha estat triada per un company, se n’ha de buscar una altra.
3. Les plataformes han de permetre observar una tasca pròxima al flux principal del projecte. No és necessari que siguin idèntiques.
4. Cal indicar les URL, data de consulta i dispositiu. No cal comprar ni pagar, ni introduir dades personals reals: es pot analitzar el flux fins abans de la confirmació definitiva.

**Idees de tasques segons projecte:**

| Rocanolich             | Buscar una cursa, consultar-ne les característiques i iniciar la inscripció |
| Estètica i perruqueria | Seleccionar un servei i arribar fins a la confirmació d’una cita            |
| Graduació              | Consultar un esdeveniment i seleccionar seients o entrades                  |

## 3. Com fer l’anàlisi (passos)

1. **Selecciona i registra** les dues plataformes amb la resta del grup.
2. Defineix **una tasca equivalent** que intentaràs fer a les dues plataformes.
3. Recorre cada plataforma com ho faria un usuari potencial. Anota passos, dificultats, missatges i punts positius.
4. Examina els resultats a la llum de les **10 heurístiques de Nielsen** (guia de l’apartat 4).
5. Recull **captures de pantalla** i referencia-les dins del document, indicant què mostren. Si una pantalla conté dades personals, oculta-les.
6. Completa la fitxa de cada plataforma, la comparativa i les conclusions. Incorpora aquest apartat al dossier individual de la tasca 1.

## 4. Les 10 heurístiques de Nielsen — guia de consulta

| Núm. | Heurística                                               | Què cal observar?                                                                  | Exemple vinculat als projectes                                           |
| ---: | -------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
|   H1 | Visibilitat de l’estat del sistema                       | El sistema informa què està passant i quin és el resultat de les accions?          | Mostra clarament que la reserva s’està processant o s’ha completat.      |
|   H2 | Correspondència entre sistema i món real                 | Fa servir paraules, conceptes i ordres comprensibles per a l’usuari?               | Parla de «pistes disponibles», «cita» o «butaques», no de codis interns. |
|   H3 | Control i llibertat de l’usuari                          | És possible tornar enrere, editar o cancel·lar accions quan correspon?             | Permet canviar el dia abans de confirmar la cita.                        |
|   H4 | Consistència i estàndards                                | Botons, icones, etiquetes i patrons de navegació són coherents?                    | El botó «Continuar» té el mateix estil i significat a totes les passes.  |
|   H5 | Prevenció d’errors                                       | El disseny evita que l’usuari cometi errors?                                       | No permet escollir una butaca que ja està ocupada.                       |
|   H6 | Reconeixement abans que record                           | Les opcions i la informació necessària són visibles sense haver de memoritzar-les? | El resum de la selecció es mostra durant la reserva.                     |
|   H7 | Flexibilitat i eficiència d’ús                           | Els usuaris nous i habituals poden completar la tasca amb agilitat?                | Permet filtrar per data o localitzar un servei ràpidament.               |
|   H8 | Disseny estètic i minimalista                            | La pantalla mostra informació rellevant sense sobrecarregar-la?                    | El calendari destaca horaris i disponibilitat sense soroll visual.       |
|   H9 | Ajuda a reconèixer, diagnosticar i recuperar-se d’errors | Els errors s’expliquen de manera clara i proposen com solucionar-los?              | «Aquest horari ja no està disponible. Escull-ne un altre».               |
|  H10 | Ajuda i documentació                                     | Hi ha ajuda accessible quan l’usuari la necessita?                                 | Explica les condicions de cancel·lació o com seleccionar seients.        |

> **Atenció:** les heurístiques són criteris per observar, **no una llista d’errors que s’hagin de trobar obligatòriament**. Pots descriure un punt ben resolt o indicar «No observat / No aplicable» amb una justificació.

### Escala orientativa de gravetat

- **0 — Sense problema:** el comportament és correcte o és una bona pràctica.
- **1 — Menor:** petita molèstia que no impedeix la tasca.
- **2 — Moderat:** dificulta el procés o provoca confusió.
- **3 — Greu:** bloqueja o posa en risc completar la tasca.
- **N/O — No observat:** no s’ha pogut comprovar; cal explicar el motiu.
