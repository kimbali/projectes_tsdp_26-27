# TSDP2 · Entrega 1 · Tasca 3 — Creació del User Persona

**TSDP2 · Entrega 1 — Anàlisi UX · Criteri 7.1.2**

## 1. Què és un User Persona i per què el necessitem?

Un **User Persona** és un personatge fictici que representa un tipus d'usuari real del nostre producte digital. Li donem **nom i cognoms**, edat, necessitats, objectius i frustracions perquè sigui més fàcil entendre per a qui estem dissenyant.

Posar-li nom i cognoms ens ajuda a deixar de pensar en «els usuaris» com un grup abstracte i a prendre decisions pensant en una persona concreta.

> La Marta Solé, de 48 anys, que acostuma a reservar des del mòbil i té poc temps, entendria com seleccionar una cita sense necessitar ajuda?

Un User Persona **no s'ha d'inventar aleatòriament**: cal basar-lo en la informació recollida a les entrevistes de la tasca 1. Si falta alguna dada, es pot formular una hipòtesi, però s'ha d'indicar que ho és. No feu servir dades personals identificables de persones entrevistades.

## 2. Enunciat de l'exercici

Cada equip de treball (Rocanolich, estètica i perruqueria, o graduació) haurà de consensuar **un User Persona principal** per al seu projecte.

**El treball de definició és grupal, però l'anàlisi i l'entrega són individuals.** Cada alumne incorporarà el perfil consensuat al **dossier individual de Google Drive iniciat a la tasca 1**, després de l'apartat 2 (Investigació UX). No cal lliurar un document separat.

## 3. Pautes de treball

| Fase            | Organització | Què heu de fer?                                                                  |
| --------------- | ------------ | -------------------------------------------------------------------------------- |
| 1. Revisió      | Grupal       | Posar en comú les conclusions de les entrevistes individuals.                    |
| 2. Selecció     | Grupal       | Triar quin tipus d'usuari representa millor el públic principal i justificar-ho. |
| 3. Creació      | Grupal       | Definir el perfil complet a partir de les evidències disponibles.                |
| 4. Anàlisi      | Individual   | Explicar les decisions UX i funcionals derivades del perfil.                     |
| 5. Documentació | Individual   | Incorporar el perfil i l'anàlisi al dossier personal.                            |

### Camps obligatoris de la fitxa de User Persona

| Camp                  | Què ha de contenir?                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| Nom i cognoms         | Nom fictici però realista.                                                                         |
| Fotografia            | Imatge il·lustrativa amb permís d'ús; no feu servir fotografies d'entrevistats sense consentiment. |
| Edat i ocupació       | Dades coherents amb l'usuari objectiu.                                                             |
| Context d'ús          | Quan, on i per què utilitzaria la plataforma.                                                      |
| Competències digitals | Familiaritat amb webs, aplicacions i reserves en línia.                                            |
| Objectiu principal    | Què vol aconseguir.                                                                                |
| Necessitats           | **Mínim 3** necessitats concretes.                                                                 |
| Frustracions          | **Mínim 3** problemes o obstacles.                                                                 |
| Motivacions           | Per què voldria utilitzar la plataforma.                                                           |
| Frase representativa  | Frase fictícia que resumeixi la seva perspectiva; no la presenteu com una cita real.               |
| Fonamentació          | Quines observacions de les entrevistes sustenten el perfil i quines dades són hipòtesis.           |

### Plantilla per copiar al dossier

**Nom i cognoms:** …

**Motivacions:** …

## 4. Requisits mínims de l'entrega

- [ ] Un User Persona principal **consensuat per tot l'equip**.
- [ ] Fitxa amb tots els camps obligatoris i **nom i cognoms ficticis**.
- [ ] **Tres necessitats i tres frustracions** com a mínim.
- [ ] Justificació basada en resultats de les entrevistes; hipòtesis assenyalades.
- [ ] **Tres preguntes d'anàlisi individual** respostes.
- [ ] **Dues decisions funcionals** i **una decisió de disseny** concretes i justificades.
- [ ] Apartat **«3. User Persona»** afegit al **mateix dossier individual de Google Drive** de les tasques 1 i 2.

## 6. Ampliació voluntària

Crea un **segon User Persona** amb un perfil i necessitats diferents (per exemple, un responsable d'administració en comptes d'un client o participant). Compara els dos perfils i explica quines funcionalitats o decisions d'interfície canviarien per satisfer-los.
